# Cloud setup

LifeOS is a Markdown framework. It has no build, runtime dependencies, startup command, required environment variables, or required secrets.

Configure the agent environment to read `AGENTS.md` at the start of each session. LifeOS protocols live in `protocols/`; read the matching protocol when a trigger is used.

The public framework repository is a clean template. Do not initialize it with personal LifeOS state or commit initialized personal state to it. Create a private repository or local copy for personal data, and review changes before publishing.
